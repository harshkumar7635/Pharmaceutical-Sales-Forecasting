# Pharmaceutical Sales Forecasting

## Project Overview
This project analyzes historical pharmaceutical sales data and forecasts future weekly sales using time-series forecasting techniques in Python.

## Objectives
- Analyze historical pharmaceutical sales trends.
- Build and compare forecasting models.
- Evaluate model performance using MAE and RMSE.
- Forecast future sales to support demand planning and inventory management.

## Forecasting Models
- Naive Forecast
- Holt's Exponential Smoothing
- Seasonal Naive Forecast
- SARIMA

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Statsmodels
- Scikit-learn
- Jupyter Notebook

## Model Evaluation
Models are compared using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE). In the notebook's current evaluation, Holt's Exponential Smoothing performed best among the four models tested.

## Project Files
- `Pharmaceutical_Sales_Forecasting.ipynb` — analysis, model training, evaluation, and forecasting.
- `salesweekly.csv` — weekly sales dataset.
- `pharmaceutical_sales_forecast.xls` — uploaded forecast file.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or JupyterLab.
4. Run the cells in order.

## Disclaimer
Forecasts are estimates based on historical data and may not reflect actual future sales.
